# Lecture 03: AI एजेंट

## इस Lecture के उद्देश्य

- AI एजेंट की मूल संरचना "मॉडल + लूप + टूल" समझें।
- Pydantic AI से टूल इस्तेमाल करने वाला अध्ययन सहायक एजेंट स्वयं बनाएँ और चलाएँ।

## मुख्य बिंदु

1. **एजेंट**: ऐसा सिस्टम जिसमें LLM टूल बुलाता है, परिणाम देखकर अगला कदम चुनता है और यह लूप चलाकर लक्ष्य पूरा करता है।
2. **टूल**: मॉडल टूल का नाम, विवरण और तर्क के प्रकार देखकर कॉल माँगता है; प्रोग्राम उसे चलाता है। विवरण का लेखन व्यवहार बदलता है।
3. **एजेंट लूप की लागत**: एक प्रश्न में LLM को कई बार कॉल किया जाता है, इसलिए उत्तर समय, खर्च और दर सीमा पर असर पड़ता है।
4. **हार्नेस**: Claude Code और Pi जैसे प्रोग्राम LLM को लूप, टूल और UI से जोड़ते हैं। Pi का हल्का हार्नेस केवल चार अंतर्निहित टूल (`read`, `write`, `edit`, `bash`) रखता है।
5. **फ़्रेमवर्क**: Pydantic AI (इस Lecture में मुख्य रूप से इस्तेमाल होने वाला फ़्रेमवर्क) प्रकारों से टूल और आउटपुट परिभाषित करता है; TestModel से API कॉल किए बिना परीक्षण हो सकता है। ADK Google का फ़्रेमवर्क है, जिसमें `adk web` से प्रक्रिया स्क्रीन पर देख सकते हैं।
6. **गार्डरेल और Human-in-the-loop**: लिखने जैसे कठिनाई से वापस लिए जाने वाले कामों के लिए सीमित अनुमति या मानव पुष्टि रखें।
